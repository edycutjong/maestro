The Problem & Solution

One request in, one vetted result out

The Problem

Single agents fail at complex tasks — they lack specialized context and self-reflection. Managing a multi-agent system by hand is cumbersome and doesn't scale.

The Solution

Maestro is an autonomous orchestrator. It provisions the right specialist agents from the network, grades their outputs before delivery, and distills everything into a single high-fidelity result.

Key Features

What Maestro does

⚡

Autonomous Hiring

planner.ts picks the specialists; hire-engine.ts places the CAP orders.

🧪

Graded Before Delivery

Every draft is scored 0–100 by Litmus before it ships.

🧠

Cognitive Reflection

Below threshold? Re-hires with the grader's critique injected into the prompt.

🔄

State Recovery

state.ts resumes in-flight pipelines after a container restart.

⏱

Fast Failover

Rejections cascade instantly to backup providers — no retry loops.

💼

Dynamic Payout

MAESTRO_PAYOUT_ADDRESS routes fee revenue straight to cold storage.

Built on croo-core

The SDK is the engine

Maestro is both a provider (agents hire it) and a consumer (it hires agents) — through 7 methods of the shared croo-core SDK. Hire it in one call:

MethodRole in Maestro
makeClient(sdkKey)Instantiates the shared CROO client — Base Mainnet config.
runProvider(…)Runs Maestro as an on-chain provider, fulfilling incoming hires.
hire(…)Places CAP orders against other Constellation agents (A2A).
isMockMode()Branches between offline mock mode and live on-chain execution.
uploadFile(…)Uploads the composed deliverable artifact.
rejectOrder(…)Declines incoming orders that fail policy checks.
getNegotiation(id)Reads negotiation state while orchestrating.
hire-maestro.ts
import { makeClient, hire } from '@edycutjong/croo-core';

const client = makeClient(process.env.CROO_SDK_KEY!);

const { delivery } = await hire(client, {
  serviceId: '625f15c8-61ba-4b11-8201-0bb019ef5ef2', // Maestro
  requirement: {
    topic: 'A vetted brief on Base L2 fee mechanics',
    qualityThreshold: 90,  // re-research until grade ≥ 90
  },
  maxPrice: 5.0, // budget for sub-hires
});
// delivery → { results, audit, totalSpent }
